1. Tenant parameter

How tenant is selected
  1. --tenant=<id> on the CLI (highest priority)
  2. TEST_TENANT_ID or E2E_TENANT_ID
  3. TestSprite/admin-tests/auth.json → tenantId
  4. Default tenant_demo_002

Expected tenant defaults to tenant_demo_002 (E2E_EXPECTED_TENANT). Set E2E_ALLOW_ANY_TENANT=1 to bypass the hard check.

Admin pages are opened as /admin/…?tenant=<id> and the sticky tenant bar is filled when needed (platform-admin-test-tenant.js).

2. Port (default 3001)

Dynamic base URL

For event-site-manager, the default app URL is http://localhost:3001 (matches auth.json.example).

OverrideExample
CLI port--port=3001 or --port=3000
CLI URL--base-url=http://localhost:3001
EnvTEST_BASE_URL / TEST_PORT
auth.json"baseUrl": "http://localhost:3001"

Priority: CLI → env → auth.json → default :3001. Probe fallback: 3001 → 3000 → 3002.

3. Prerequisites

Before you run
  • npm install + npm run test:install-playwright
  • App running on :3001 by default (npm run dev) — or pass --port= to match
  • Copy auth.json.example → auth.json (ADMIN email/password + tenantId + baseUrl)

5. Recommended command

Admin + public · tenant_demo_002
Use & between Node steps so CRUD and smoke still run if comprehensive exits non-zero. 
cmd /c "set TEST_TENANT_ID=tenant_demo_002&& set E2E_TENANT_ID=tenant_demo_002&& set E2E_EXPECTED_TENANT=tenant_demo_002&& set TEST_BASE_URL=http://localhost:3001&& node TestSprite\tools\generate-route-inventory.js & node TestSprite\admin-tests\comprehensive-admin-test-suite.js --port=3001 & node TestSprite\admin-tests\admin-crud-demo-tenant-suite.js --tenant=tenant_demo_002 --port=3001 & node TestSprite\sanity-tests\run-inventory-smoke-crawl.js --kind=admin,public --tenant=tenant_demo_002 --port=3001"

Quick orchestrator (default port 3001 for event-site-manager; inventory → public dynamic → CRUD → smoke; not test:admin:all):

cmd /c "set TEST_BASE_URL=http://localhost:3001&& node TestSprite\run-e2e-full.js --quick --tenant=tenant_demo_002 --port=3001"

If the app is on port 3000:

cmd /c "set TEST_BASE_URL=http://localhost:3000&& node TestSprite\run-e2e-full.js --quick --tenant=tenant_demo_002 --port=3000"
Look for [e2e-full] Mode: QUICK and step banners. Reports land in TestSprite/reports/. admin-test-report.html is only from npm run test:admin:all. Default base URL is http://localhost:3001. Override with --port=, --base-url=, or TEST_BASE_URL. Fallback probe order: 3001 → 3000 → 3002.

7. REST / proxy notes

Aligned with nextjs_api_routes.mdc
  • UI and discovery use /api/proxy/… — never call the backend base URL from the browser.
  • Do not add tenantId.equals when calling the proxy (handler injects it).
  • Admin page scope uses ?tenant= for the platform-admin UI context (separate from proxy injection).
  • ID discovery for dynamic routes uses public proxy list GETs (event-details, membership-plans, etc.).
