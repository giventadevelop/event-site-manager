1. Executive Summary

This document covers the complete investigation and resolution of three interconnected authentication failures affecting both the primary domain (event-site-manager.com) and satellite domain (mosc-temp.com). The root cause was a misconfigured FAPI proxy that was missing required headers, which broke all authentication methods (Google OAuth, email verification, and session management).

2. Issues Encountered

2.1 Satellite Domain Sign-Out Bug

🐛 Problem

After signing out from the primary domain (event-site-manager.com), the satellite domain (mosc-temp.com) still showed the user as logged in — avatar and Admin menu remained visible. The sign-out redirect appended ?clerk_signout=true to the satellite URL, but the satellite's Header component only cleared localStorage.

Why this didn't work: Clerk stores session tokens in HTTP-only cookies, which cannot be cleared via JavaScript's localStorage.removeItem(). Only Clerk's signOut() API can clear these cookies because it makes a server call to invalidate the session.

2.2 Google OAuth authorization_invalid Error

🐛 Problem

After the sign-out fix was deployed and working, login via Google OAuth broke on both the primary and satellite domains.

2.3 Email Verification Code Not Arriving

🐛 Problem

Email/password login also failed. After entering an email address, the verification code email never arrived. The sign-in form displayed "you are signed out" during the verification step. Tested with multiple email addresses and in incognito mode — same result.

2.4 Root Cause: FAPI Proxy Missing Headers

🔴 ROOT CAUSE (confirmed by Clerk Support — Jordan):

The application was using a plain Next.js rewrite rule to proxy Clerk FAPI requests through /__clerk/*. This basic rewrite did not forward three required headers that Clerk's backend needs to accept proxied requests:

  1. Clerk-Proxy-Url — the full proxy URL
  2. Clerk-Secret-Key — the Clerk secret key for server-side verification
  3. X-Forwarded-For — the original client's IP address

Without these headers, Clerk's backend rejected all proxied requests, which explains why both Google OAuth and email verification failed simultaneously.

💡 Why the proxy exists:

The Clerk publishable key encodes the FAPI domain as clerk.event-site-manager.com (no www). But the site runs at www.event-site-manager.com. Without a proxy, Clerk tries to reach clerk.www.event-site-manager.com which doesn't exist in DNS. The proxy routes /__clerk/* through the app's own domain to avoid this DNS mismatch.

⚠️ Additional contributing factor — Google OAuth:

The Google Cloud Console OAuth consent screen was in "Testing" mode (project named oauthlocal-310103). This was promoted to "In production" during debugging. A new client secret was also generated and updated in the Clerk Dashboard.

5. Fix 1: Satellite Domain Sign-Out

✅ Fix Applied to mosc-temp Header.tsx

File: E:\project_workspace\mosc-temp\src\components\Header.tsx

Old Code (Broken — only cleared localStorage):

❌ Removed
// Old approach: Only cleared localStorage — insufficient!
// Clerk stores sessions in HTTP-only cookies that JS can't access.
useEffect(() => {
  const urlParams = new URLSearchParams(window.location.search);
  const clerkSignedOut = urlParams.get('clerk_signout');
  if (clerkSignedOut === 'true') {
    Object.keys(localStorage).forEach(key => {
      if (key.includes('clerk') || key.includes('__clerk')) {
        localStorage.removeItem(key);
      }
    });
    window.location.reload();
  }
}, []);

New Code (Fixed — calls signOut() to clear cookies):

✅ Added
// Two-phase approach: Wait for Clerk to load, then call signOut()
const [pendingSignOut, setPendingSignOut] = useState(false);

// Phase 1: Detect flag on mount (runs before Clerk loads)
useEffect(() => {
  if (typeof window === 'undefined') return;
  const urlParams = new URLSearchParams(window.location.search);
  const clerkSignedOut = urlParams.get('clerk_signout');
  if (clerkSignedOut === 'true') {
    setPendingSignOut(true);
    // Clean URL immediately
    urlParams.delete('clerk_signout');
    const newUrl = window.location.pathname +
      (urlParams.toString() ? '?' + urlParams.toString() : '');
    window.history.replaceState({}, '', newUrl);
  }
}, []);

// Phase 2: Once Clerk is loaded, call signOut()
useEffect(() => {
  if (!pendingSignOut || !isLoaded) return;
  const performSignOut = async () => {
    try {
      await signOut();
    } catch (error) {
      console.error('[Header] signOut() error:', error);
    }
    // Clear localStorage as backup
    Object.keys(localStorage).forEach(key => {
      if (key.includes('clerk') || key.includes('__clerk')) {
        localStorage.removeItem(key);
      }
    });
    setPendingSignOut(false);
    window.location.replace(window.location.pathname);
  };
  performSignOut();
}, [pendingSignOut, isLoaded, signOut]);
