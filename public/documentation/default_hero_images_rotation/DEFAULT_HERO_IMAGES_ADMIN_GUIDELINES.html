1. What this controls

Tenant default homepage hero images appear when there is no upcoming event with hero media, or as trailing slides when Include with events is enabled. Settings live on the Homepage Hero tab in Tenant Settings.

2. Before you upload (create mode)

Save tenant settings first. On a new tenant settings record, uploads are disabled until you save once and return to Edit — the same pattern as logo upload.

3. Upload rules

  • Drag-and-drop or click Browse to add images.
  • Formats: PNG, JPG, JPEG, WEBP, GIF.
  • Max file size: 10 MB per file.
  • Recommended dimensions: 2000×800 (5:2 landscape).
  • Max library size: 20 images total.
  • When a settingsId exists, successful uploads auto-save enriched JSON to tenant settings.

4. Library vs active

The library holds every uploaded slide. Only slides marked Active participate in homepage selection. New uploads default to Inactive — you must opt in each slide before it can appear on the homepage.

5. Mark slides active

  • Use the Active / Inactive toggle on each thumbnail.
  • Maximum 10 active slides at once.
  • Drag thumbnails to reorder — order matters for the active subset and slideshow mode.

6. Homepage display count

Select 1–6 (default 6). When at least one slide is active, the homepage shows min(active count, display count) slides from the active pool (in order).

7. Zero active fallback

If no slides are marked active but the library is non-empty, the homepage picks 3 random images from the full library on each page resolve (refresh may show different slides).

8. Display mode

Applied after active / random-3 resolution:

  • Slideshow — rotate through all selected URLs.
  • Random — one URL per page load.
  • Single — first URL only.

9. Include with events

When checked, tenant default slides append after upcoming event hero images on the homepage. When unchecked, defaults only appear when no event hero media exists.

10. Homepage fallback chain

Resolution order (first match wins):

  1. Upcoming event hero media (if any)
  2. Tenant default slides (active rules, display count, random-3, display mode)
  3. Bundled fallback image: /images/hero_section/hero_images/fallback/default-hero.webp

11. Legacy data

Plain URL JSON arrays (e.g. ["https://..."]) continue to show all URLs on the homepage until an admin saves from this UI — which migrates to enriched [{ "url", "active" }] format.

12. Manual URLs (advanced)

Paste HTTPS URLs one per line. They are merged as inactive slides and deduplicated by URL. Mark them active individually if you want them on the homepage.

13. Verify on the homepage

  1. Click Save on tenant settings.
  2. Open the public homepage in a new tab.
  3. Test with and without upcoming events (and with Include with events on/off).
  4. Confirm rotation, display count, and fallback behavior match your expectations.
