What are satellite domains?

A satellite domain is a tenant's custom public URL (for example https://www.mosc-temp.com) that runs the same application as your primary domain (for example https://www.event-site-manager.com). Each satellite is linked to a Tenant ID so the site loads the correct organization, settings, events, and branding.

Login & sign-up require a satellite domain record. Users who visit a custom domain must sign in through Clerk's satellite authentication flow. The app redirects them to the primary domain for sign-in, then back to the satellite after success. If the hostname is not registered under Admin → Satellite Domains, sign-in and sign-out on that custom URL will not work correctly.

Recommended setup workflow

  1. Create a tenant organization (Admin → Organizations). Note the organization's tenantId — this is the key used everywhere else.
  2. Create tenant settings (Admin → Tenant Settings) and link them to that organization. Set logo, contact info, and feature flags. The tenantId on settings must match the organization.
  3. Register the satellite domain at Admin → Satellite Domains:
    • Satellite Key — short identifier (e.g. mosc-temp)
    • Domain URL — full URL with scheme (e.g. https://www.mosc-temp.com)
    • Hostname — host only (e.g. www.mosc-temp.com)
    • Tenant ID — must match tenant settings / organization
    • Enabled — turn on when DNS and Clerk are ready
  4. Configure DNS (AWS Amplify custom domain or CNAME) so the hostname points to your deployed app.
  5. Configure Clerk — add the hostname as a satellite domain in the Clerk Dashboard (Production). The primary domain must remain deployed; satellite auth depends on it.
  6. Optional branding — on the satellite form, logo and theme fields can mirror tenant settings; entering the Tenant ID loads the logo from tenant settings as a reference.

Field reference (Satellite Domains admin)

Field Purpose
tenantId Must match Tenant Settings and Organization. Wrong ID = wrong tenant data and broken auth context.
hostname Used to detect satellite vs primary at runtime (sign-in redirect, branding, tenant resolution).
domain Full public URL; used in links and Clerk configuration.
enabled Disable temporarily without deleting the record (maintenance, pre-launch).
Auth header/footer flags Control whether org branding appears on sign-in and sign-out pages for this satellite.
Primary domain must stay online. Satellite sign-in redirects users to the primary app for Clerk authentication. If the primary deployment is removed, users on satellite domains cannot complete login or sign-out.
